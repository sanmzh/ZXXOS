# ASLR (Address Space Layout Randomization) 实现文档

## 1. ASLR 简介

### 1.1 什么是ASLR
地址空间布局随机化（Address Space Layout Randomization，ASLR）是一种计算机安全技术，通过随机化进程数据空间中关键数据区域的地址来防止攻击者预测目标地址。这些关键区域包括程序的可执行代码、堆、栈和库文件等。

### 1.2 ASLR的作用
- **防止代码注入攻击**：通过随机化代码段地址，使攻击者难以预测跳转目标
- **防止返回导向编程(ROP)**：通过随机化库函数地址，使攻击者难以构建ROP链
- **防止堆溢出攻击**：通过随机化堆地址，使攻击者难以覆盖特定目标
- **防止栈溢出攻击**：通过随机化栈地址，使攻击者难以覆盖返回地址

### 1.3 ASLR的实现原理
ASLR通过在进程加载时为不同的内存段添加随机偏移量来实现：
- **代码段随机化**：随机化可执行代码的加载地址
- **堆随机化**：随机化堆内存的起始地址
- **栈随机化**：随机化栈内存的起始地址
- **库文件随机化**：随机化共享库的加载地址

## 2. 实现细节

### 2.1 随机数生成
我们使用线性同余生成器(LCG)作为随机数生成器：

```c
int get_random_min_max(int min, int max) 
{
  int randomNum = 0;
  // 使用全局随机种子
  extern uint64 g_random_seed;
  
  // 线性同余生成器算法
  g_random_seed = g_random_seed * 1103515245 + 12345;
  randomNum = (g_random_seed / 65536) % (max - min + 1) + min;
  
  return randomNum;
}
```

### 2.2 代码段随机化
在exec.c中实现代码段地址随机化：

```c
// 如果ASLR标志开启，创建base_pointer_offset变量并赋值为get_random_min_max(0,16)
// 如果标志关闭，则赋值为0
int base_pointer_offset = aslr_enabled ? get_random_min_max(0, 16) : 0;

// 如果ASLR标志开启，创建text_seg_pages_offset变量并赋值为base_pointer_offset * PGSIZE
// 否则赋值为0
uint64 text_seg_pages_offset = aslr_enabled ? base_pointer_offset * PGSIZE : 0;

// 在ELF加载过程中应用偏移量
// 通过修改页表映射来实现代码段的随机化
```

### 2.3 堆随机化
通过随机化堆分配的页面数量来实现：

```c
// 创建变量num_pages并初始化为2
int num_pages = 2;

// 如果ASLR标志开启，创建add_pages变量并赋值为num_pages + get_random_min_max(0,8)
// 将add_pages加到num_pages上
if (aslr_enabled) {
  int add_pages = get_random_min_max(0, 8);
  num_pages += add_pages;
}

// 使用num_pages进行堆内存分配
// 这会导致堆的起始地址发生变化
```

### 2.4 栈随机化
通过调整栈指针来实现：

```c
// 如果ASLR标志开启，创建stack_offset变量并赋值为get_random_min_max(0,16)
// 通过从sz中减去stack_offset*64来改变栈指针sp
if (aslr_enabled) {
  int stack_offset = get_random_min_max(0, 16);
  sp -= stack_offset * 64;  // 通过随机偏移量调整栈指针
}
```

### 2.5 随机种子管理
- **初始化**：在proc.c中定义全局随机种子并初始化
  ```c
  // ASLR随机种子
  uint64 g_random_seed = 12345;
  ```

- **更新**：在trap.c的kerneltrap函数中更新随机种子
  ```c
  // 更新ASLR随机种子
  extern uint64 g_random_seed;
  g_random_seed++;
  ```
