# 手动测试文件权限功能指南

## 基本测试步骤

### 1. 启动系统
```bash
make qemu
```

### 2. 测试chmod命令

#### 创建测试文件
```sh
$ echo "test content" > testfile.txt
$ ls -l testfile.txt
```

#### 修改文件权限
```sh
# 设置为只有所有者可读写
$ chmod 600 testfile.txt
$ ls -l testfile.txt

# 设置为所有用户可读写
$ chmod 666 testfile.txt
$ ls -l testfile.txt

# 设置为所有者可读写执行，组和其他用户只读
$ chmod 644 testfile.txt
$ ls -l testfile.txt

# 设置为所有用户可读写执行
$ chmod 777 testfile.txt
$ ls -l testfile.txt
```

### 3. 测试chown命令

#### 修改文件所有权
```sh
# 查看当前文件所有者
$ ls -l testfile.txt

# 将文件所有权设置为用户0，组0
$ chown 0:0 testfile.txt
$ ls -l testfile.txt

# 将文件所有权设置为用户1，组1
$ chown 1:1 testfile.txt
$ ls -l testfile.txt

# 只修改用户，不修改组
$ chown 2 testfile.txt
$ ls -l testfile.txt
```

### 4. 测试访问控制

#### 测试读取权限
```sh
# 创建文件并设置权限
$ echo "secret content" > secret.txt
$ chmod 600 secret.txt  # 只有所有者可读写

# 尝试读取文件
$ cat secret.txt  # 应该成功

# 修改权限为只有所有者可读
$ chmod 400 secret.txt
$ cat secret.txt  # 应该成功

# 尝试写入文件
$ echo "new content" > secret.txt  # 应该失败，因为只有读权限
```

#### 测试目录权限
```sh
# 创建测试目录
$ mkdir testdir
$ ls -ld testdir

# 设置目录权限
$ chmod 700 testdir  # 只有所有者可读写执行
$ ls -ld testdir

# 尝试进入目录
$ cd testdir  # 应该成功

# 在目录中创建文件
$ touch testdir/file.txt  # 应该成功

# 退出目录
$ cd ..

# 修改目录权限
$ chmod 555 testdir  # 所有用户可读和执行，但不能写
$ ls -ld testdir

# 尝试进入目录
$ cd testdir  # 应该成功

# 尝试在目录中创建文件
$ touch testdir/file2.txt  # 应该失败，因为没有写权限
```

### 5. 测试用户切换和权限

#### 创建不同用户并测试
```sh
# 创建测试用户
$ useradd
# 按提示输入用户名和密码

# 切换用户（如果实现了su命令）
$ su username
# 输入密码

# 尝试访问属于其他用户的文件
$ cat other_user_file.txt  # 应该失败或成功取决于权限设置
```

### 6. 测试set-user-ID功能（如果已实现）

#### 创建set-user-ID程序
```sh
# 创建一个简单的程序
$ cat > suid_test.c << 'EOF'
#include "kernel/types.h"
#include "kernel/stat.h"
#include "user/user.h"

int main() {
    printf("Effective UID: %d\n", getuid());
    return 0;
}
EOF

# 编译程序
$ cc suid_test.c -o suid_test

# 设置set-user-ID位
$ chmod 4755 suid_test
$ ls -l suid_test

# 运行程序
$ ./suid_test  # 应该显示文件所有者的UID，而不是当前用户的UID
```

## 验证方法

### 1. 检查文件权限
使用`ls -l`命令查看文件权限和所有权：
```sh
$ ls -l filename
```
输出格式：`-rwxr-xr-x 1 uid gid size date filename`

### 2. 检查当前用户ID
```sh
$ whoami
```

### 3. 检查系统调用返回值
如果需要调试，可以修改程序打印系统调用的返回值：
```sh
$ cat > debug_chmod.c << 'EOF'
#include "kernel/types.h"
#include "kernel/stat.h"
#include "user/user.h"

int main(int argc, char *argv[]) {
    if (argc != 3) {
        printf("Usage: %s mode filename\n", argv[0]);
        exit(1);
    }
    
    int mode = atoi(argv[1]);
    int ret = chmod(argv[2], mode);
    printf("chmod returned: %d\n", ret);
    
    if (ret == 0) {
        printf("Success\n");
    } else {
        printf("Failed\n");
    }
    
    exit(0);
}
EOF
```

## 预期结果

1. **chmod命令**：应该能够成功修改文件权限，并且`ls -l`显示的权限应该与设置的一致
2. **chown命令**：应该能够成功修改文件所有权，并且`ls -l`显示的UID和GID应该与设置的一致
3. **访问控制**：当用户没有相应权限时，应该无法执行相应操作（读取、写入、执行等）
4. **set-user-ID**：如果实现，设置set-user-ID位的程序在执行时应该具有文件所有者的权限

## 故障排除

1. **命令不存在**：确保已将chown和chmod添加到Makefile的UPROGS列表中
2. **权限不生效**：检查内核中的access函数是否正确实现
3. **所有权不正确**：检查inode结构是否正确添加了uid和gid字段
4. **系统调用失败**：检查系统调用号是否正确映射，以及用户空间声明是否正确
