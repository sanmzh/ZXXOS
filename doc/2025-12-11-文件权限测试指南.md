# 文件权限和所有权测试指南

## 1. 重新编译系统

首先，需要重新编译xv6系统以包含新添加的chown和chmod命令：

```bash
make clean
make
```

## 2. 启动系统并运行测试

启动xv6系统：

```bash
make qemu
```

系统启动后，登录并运行测试程序：

```bash
perms_test
```

## 3. 手动测试文件权限

### 测试chmod命令

1. 创建一个测试文件：
```bash
echo "test content" > test.txt
```

2. 查看当前文件权限：
```bash
ls -l test.txt
```

3. 修改文件权限为只有所有者可读写：
```bash
chmod 600 test.txt
```

4. 再次查看文件权限：
```bash
ls -l test.txt
```

5. 修改文件权限为所有用户可读写：
```bash
chmod 666 test.txt
```

6. 再次查看文件权限：
```bash
ls -l test.txt
```

### 测试chown命令

1. 查看当前用户ID：
```bash
whoami
```

2. 将文件所有权设置为当前用户：
```bash
chown 1000:1000 test.txt
```

3. 验证所有权是否已更改（需要实现stat命令或ls -l显示所有者）

## 4. 测试访问控制

1. 创建一个受限文件：
```bash
echo "restricted content" > restricted.txt
```

2. 设置文件权限为只有所有者可读写：
```bash
chmod 600 restricted.txt
```

3. 尝试以不同用户身份访问文件（需要实现用户切换功能）

## 5. 预期结果

- chmod命令应该能够成功修改文件权限
- chown命令应该能够成功修改文件所有权
- 文件访问权限应该根据设置的权限位正确工作
- 非所有者用户应该无法访问权限受限的文件

## 6. 故障排除

如果测试失败，检查以下几点：

1. 系统调用是否正确注册：
   - 检查sysnum.h中的系统调用号
   - 检查syscall.c中的系统调用映射
   - 检查usys.pl中的用户空间接口

2. 内核实现是否正确：
   - 检查sys_chmod和sys_chown函数实现
   - 检查accessi函数的权限检查逻辑

3. 用户程序是否正确：
   - 检查chown.c和chmod.c的实现
   - 确保它们正确调用系统调用

4. 文件系统是否支持权限：
   - 检查inode结构是否包含uid、gid和mode字段
   - 检查文件创建时是否正确设置这些字段
