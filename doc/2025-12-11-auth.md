# xv6 认证与访问控制系统实现文档

## 概述

本文档描述了在xv6操作系统中实现的认证与访问控制系统。该系统提供了用户账户管理、密码认证、进程身份标识和基于文件权限的访问控制功能，使xv6能够支持多用户环境下的安全操作。

## 实现原因

在原始的xv6系统中，所有进程都以相同的权限运行，没有用户身份的概念，这限制了系统在多用户环境中的应用。实现认证与访问控制系统的原因包括：

1. **安全性增强**：通过用户身份和权限控制，防止未授权访问系统资源
2. **多用户支持**：允许多个用户在同一系统上工作，彼此隔离
3. **最小权限原则**：每个进程只拥有完成其任务所需的最小权限
4. **教学目的**：展示操作系统核心安全机制的实现
5. **兼容性**：与POSIX标准保持一致，便于移植Unix/Linux程序

## 系统架构

xv6认证系统的架构分为三个主要层次：

1. **用户程序层**：提供用户交互界面
   - `login`：用户登录程序，验证用户身份
   - `useradd`：用户添加程序，创建新用户账户
   - `whoami`：显示当前用户身份的程序
   - `pwdtests`：用户账户管理功能测试程序

2. **系统调用接口层**：提供内核服务访问
   - `getuid()`/`getgid()`：获取当前进程的用户ID/组ID
   - `setuid()`/`setgid()`：设置当前进程的用户ID/组ID
   - 用户账户管理函数：`getpwnam()`, `getpwuid()`, `getpwent()`, `setpwent()`, `endpwent()`, `putpwent()`

3. **内核实现层**：实现核心认证功能
   - 进程身份管理：在进程结构中添加UID和GID字段
   - 用户账户存储：在文件系统中存储用户账户信息
   - 密码哈希验证：使用Jenkins哈希函数和盐值进行密码验证

## 实现步骤

### 1. 创建用户账户抽象

#### 1.1 实现`passwd.h`头文件
```c
// user/pwd.h
struct passwd {
  char *pw_name;     // 用户名
  char *pw_passwd;   // 密码哈希
  uint pw_uid;       // 用户ID
  uint pw_gid;       // 组ID
  char *pw_gecos;    // 用户信息
  char *pw_dir;      // 主目录
  char *pw_shell;    // 默认shell
};

// 函数声明
void setpwent(void);
void endpwent(void);
struct passwd *getpwent(void);
struct passwd *getpwnam(const char *name);
struct passwd *getpwuid(uint uid);
int putpwent(const struct passwd *pw);
```

#### 1.2 实现`pwd.c`文件
- 实现用户账户信息的文件存储和检索
- 使用静态变量返回`passwd`结构体指针
- 实现按用户名和UID的查找功能

### 2. 创建密码哈希系统

#### 2.1 实现`hash.h`头文件
```c
// user/hash.h
unsigned int hash_rand(void);

void generate_hashed_password(const char *password, char *hashed_password);

                                       unsigned int salt, 
                                       char *hashed_password);
```

#### 2.2 实现`hash.c`文件
- 实现Jenkins哈希函数
- 实现随机数生成器
- 实现密码加盐哈希功能

### 3. 实现进程身份

#### 3.1 修改进程结构
```c
// kernel/proc.h
struct proc {
  // ... 现有字段 ...
  uint uid;          // 用户ID
  uint gid;          // 组ID

```

#### 3.2 添加系统调用
```c
// kernel/syscall.h
#define SYS_getuid 23
#define SYS_getgid 24

// kernel/sysproc.c

```

### 4. 创建用户程序

#### 4.1 实现useradd程序
- 提示输入用户名和密码
- 生成密码哈希并创建用户账户

#### 4.2 实现login程序
- 检查passwd文件是否存在，不存在则创建root用户
- 提示输入用户名和密码
- 验证密码并设置进程身份
- 执行shell

#### 4.3 实现whoami程序
- 输出当前用户名

### 5. 修改init进程

修改`user/init.c`，使系统启动时运行`login`程序而不是直接运行shell：
```c
// user/init.c
int main(void) {
  // ... 初始化代码 ...
  
  for(;;){
    printf("init: starting login\n");
    pid = fork();
    if(pid < 0){
      printf("init: fork failed\n");
      exit(1);
    }
    if(pid == 0){
      exec("login", argv);
      printf("init: exec login failed\n");
      exit(1);
    }
    
    while((wp=wait()) >= 0 && wp != pid)
      ;
  }
}
```

## 已知问题与改进方向

### 当前限制

1. **密码安全性**
   - 使用非加密的Jenkins哈希函数，而非加密哈希函数
   - 盐值只有32位，可能不足以防止彩虹表攻击
   - 密码输入时没有隐藏显示

2. **用户账户管理**
   - 没有实现用户修改和删除功能
   - 没有实现用户组管理
   - 没有实现密码过期和复杂度检查

3. **进程身份管理**
   - 没有实现set-user-ID和set-group-ID功能
   - 没有实现有效用户ID和真实用户ID的区别

### 改进方向

1. **增强密码安全性**
   - 实现更强大的加密哈希函数（如SHA-256）
   - 增加盐值长度（至少64位）
   - 实现密码输入隐藏功能

2. **完善用户账户管理**
   - 实现用户修改和删除功能
   - 实现用户组管理
   - 实现密码过期和复杂度检查

3. **扩展进程身份管理**
   - 实现set-user-ID和set-group-ID功能
   - 实现有效用户ID和真实用户ID的区别

4. **添加访问控制功能**
   - 实现文件所有权和权限管理
   - 实现基于用户身份的文件访问控制
   - 实现访问控制列表（ACL）
